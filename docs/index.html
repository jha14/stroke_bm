问题：急性脑梗后颅骨骨髓造血发生了什么——中性粒是否扩增、粒系和 HSC 的状态由什么驱动、能否提示干预靶点。
顺序：00–06 质控与命名；07 细胞组成；08 粒系发育轴；09–11 通路、转录因子、细胞因子响应；12 把粒系拟时间与这些分数对齐；13 HSC 向 MEP / GMP / MDP 的命运。

报告

  1. 00 质控 — 过滤空液滴、双细胞和线粒体过高的细胞。
  2. 01 聚类 — Harmony 整合后聚类。
  3. 02 Marker — 经典基因核对大类位置。
  4. 03.1 导出 — 写成 CellTypist 用的 h5ad。
  5. 03.2 CellTypist — 参考标签，不是最终命名。
  6. 04 大类命名 — HSPC、B、中性粒等。
  7. 05.1 HSPC、05.2 B / 浆细胞、05.3 T / NK、05.4 单核 / DC、05.5 中性粒、05.6 红系 — 亚型命名。
  8. 06 合并 — 得到 annot_main / annot_sub。
  9. 07.1 组成 — 各例占比；Wilcoxon、miloR 为补充。
  10. 07.2 scCODA — 组成变化的主模型。
  11. 08 粒系轨迹 — GMP → 早幼粒 → Pre-Neut → 成熟粒。
  12. 09 通路 — PROGENy 推断的通路活性。
  13. 10 转录因子 — 中性粒谱系 30 个与阶段相关的 TF。
  14. 11 CytoSig — 细胞因子响应签名，不是测到的浓度。
  15. 12 拟时间与活性 — 粒系轴上的进度和通路 / TF / 细胞因子。
  16. 13 HSPC 轨迹 — HSC → MEP / GMP / MDP。

可以继续做的分析

  • 细胞通讯：HSC 和中性粒被谁影响、又影响谁。
  • 亚型水平的样本级差异基因，与通路、TF、细胞因子结果对照。
  • 把 HSC 拟时间与通路 / TF / CytoSig 对齐（12 目前对齐的是粒系轴）。
  • 组成与活性联合：GMP / 中性粒占比高的样本，细胞因子签名是否也高。

数据和实验上可以补什么

优先补同一实验室、同一套 3′ 或 5′ 的 CTRL 与 ACI，用来拆开疾病和平台。有条件再配对外周血或脑组织。

  • 测序：蛋白（CITE-seq）、空间位置、更大例数，年龄性别进入模型。
  • 功能：G-CSF / IFN 等 ELISA；体外刺激能否复现签名；ROS、NETosis、迁移。
  • 机制：共培养或阻断通讯分析里靠前的配体–受体。

通路、转录因子和 CytoSig 都是 RNA 推断，不是 ELISA 或磷酸化。性别和年龄用于选对照，未进入统计模型。
